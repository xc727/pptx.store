EVENT 03 / WORKBENCH

从上传到交付，放在一个工作台。

工作台负责上传原稿和模板、配置页数、查看日志、预览 PDF、下载 PPTX，以及后续重生成和编辑流程。

启动 PPTX 工作台 查看文献拆分
PPTXPDF 预览与 PPTX 文件交付，保留可编辑输出。
BOOK
EVENT 04 / BOOK SPLIT

文献拆分，独立工具。

拆书与 PPT 生产不绑定。它用于长文档、书籍、论文的章节拆分和知识归档，输出 Excel、Word、Markdown 等结果。

进入文献拆分 查看充值中心
PDF书籍、论文、报告、长篇资料。
DOCX支持常见文档与 Markdown 输入。
CHUNK章节切分、长段落拆解、知识层归档。
EXPORT输出 Excel、Word、Markdown，独立保存。
